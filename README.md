# پژوهش‌یار عنبیه — نسخه فارسی پژوهشی

این پروژه یک اپلیکیشن Android برای آموزش، ثبت مشاهدات عنبیه و **آزمون علمی ادعاهای عنبیه‌شناسی** است.

## هدف
- محتوای متنی PDF ارسالی کاربر به‌صورت داخلی در `app/src/main/assets/knowledge_fa.txt` قرار گرفته است.
- عکس عنبیه انتخاب می‌شود و تحلیل هندسی تقریبی انجام می‌شود.
- جستجو در متن داخلی کتاب وجود دارد.
- پروتکل اعتبارسنجی پزشکی داخل برنامه ارائه شده است.

## نکته مهم علمی
این برنامه نباید بیماری را از روی عنبیه تشخیص دهد یا نتیجه «سالم/بیمار» صادر کند. ادعاهای کتاب به‌صورت ادعاهای منبع/تفسیر سنتی نگهداری می‌شوند و برای اعتبارسنجی باید در یک مطالعه کور و با مرجع پزشکی معتبر آزمون شوند.

شواهد منتشرشده فعلی، از جمله یک مرور سیستماتیک و یک مرور/موضع‌نامه ۲۰۲۶، از اعتبار تشخیصی عنبیه‌شناسی پشتیبانی نمی‌کنند. بنابراین این پروژه عمداً «پژوهش‌یار» است، نه ابزار تشخیصی.

## ساخت APK با GitHub Actions
1. این پوشه را در یک Repository جدید GitHub قرار دهید.
2. فایل workflow در `.github/workflows/android.yml` به‌صورت خودکار APK را build می‌کند.
3. در GitHub به Actions بروید و workflow را اجرا کنید.
4. APK در بخش Artifacts قابل دریافت است.

## توسعه بعدی پیشنهادی
- بانک داده پژوهشی برای ثبت زوج «ادعای عنبیه‌شناسی ↔ مرجع پزشکی».
- ورود نتایج آزمایش/تصویربرداری پزشکی به‌صورت ناشناس.
- کورسازی دوطرفه و قفل‌کردن برچسب مرجع تا پایان ارزیابی.
- محاسبه خودکار sensitivity/specificity/PPV/NPV/Kappa/ROC.
- ثبت نسخه مدل و hash تصویر برای reproducibility.
- خروجی CSV و گزارش پژوهشی.

## مجوز محتوای کتاب
متن PDF کاربر در برنامه قرار گرفته است. برای انتشار عمومی متن کامل کتاب در GitHub یا توزیع عمومی APK، حقوق نشر/اجازه صاحب اثر را بررسی کنید.
